# Campus Placement & Internship Management System

**Team:** Team-Alpha  
**Institution:** R. D. Engineering College Research Center, Ghaziabad (AKTU)  

## ⚠️ The Problem
College placement activities currently rely on scattered tools like WhatsApp groups, emails, and manual Excel spreadsheets. This manual process creates critical bottlenecks:
* Important internship links get lost in busy chat groups.
* Placement officers waste hours manually verifying if students meet CGPA or branch requirements for specific companies.
* Students have no centralized dashboard to track the status of their applications.

## 💡 The Solution
We are building a centralized digital platform that automates the recruitment workflow for the college placement cell. 
* **For Students:** A single dashboard to build an academic profile, view active job postings, and apply with one click.
* **For Administrators:** A secure portal to post jobs, set automated eligibility rules (e.g., >7.0 CGPA), and track applicants in real-time.

## ⚙️ How It Works (Architecture & Tech Stack)
The system uses a decoupled Client-Server architecture to process applications securely:
* **Frontend (User Interface):** React.js, HTML, CSS, JavaScript
* **Backend (Business Logic):** Java, Spring Boot, REST APIs
* **Database (Persistent Storage):** PostgreSQL
* **Version Control:** Git & GitHub
